# Shreyansh Surana — Portfolio

A minimal, peaceful developer portfolio showcasing my work in backend engineering, AI-powered applications, document processing, and semantic search.

## 🌐 Live Website

**[Visit My Portfolio](https://shreyansh-surana.ai.studio)**

## ✨ Features

- Minimal design with subtle ambient animations.
- Interactive piano-like sound effects.
- Hidden 10-click musical Easter egg.
- Selected projects and engineering experience.
- Responsive design for desktop and mobile.

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Web Audio API

## 🚀 Run Locally

```bash
git clone https://github.com/Shreyansh2025/Portfolio.git
cd Portfolio
npm install
npm run dev
```
